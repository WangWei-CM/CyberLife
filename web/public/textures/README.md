# Earth texture attribution

Source repository: https://github.com/Hotragn/HotEARTH
Source file: https://raw.githubusercontent.com/Hotragn/HotEARTH/main/public/textures/earth-day-blue-marble.jpg
Original imagery: NASA Blue Marble / NASA Earth Observatory, public domain. NASA attribution is retained; no NASA endorsement is implied.
